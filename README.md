# 🚚 Entrega Rápida

## 📱 Descrição

O **Entrega Rápida** é um projeto desenvolvido com foco em dispositivos móveis e pensado para funcionar como um aplicativo instalável, mesmo sendo uma aplicação web.

A aplicação utiliza conceitos de **Progressive Web App (PWA)** para proporcionar uma experiência próxima à de um aplicativo nativo, permitindo instalação no dispositivo e utilização de recursos disponíveis no navegador.

Entre as funcionalidades planejadas estão o gerenciamento de entregas, captura de etiquetas pela câmera, reconhecimento de informações por OCR, localização GPS, mapas e organização de rotas.

## 📌 Problema

Entregadores precisam lidar diariamente com diversas informações durante suas rotas, como endereços, números de pedidos, etiquetas, localização e sequência das entregas.

Quando essas informações ficam espalhadas entre aplicativos, anotações e outros recursos, o gerenciamento da rota pode se tornar mais trabalhoso e sujeito a erros.

O **Entrega Rápida** busca centralizar essas informações em uma única aplicação, facilitando o gerenciamento das entregas durante o trabalho.

## 🎯 Objetivo

Desenvolver uma aplicação **PWA mobile-first** que permita ao entregador:

* Cadastrar e gerenciar entregas;
* Organizar as entregas durante a rota;
* Utilizar a câmera para leitura de etiquetas;
* Extrair informações de endereços utilizando OCR;
* Utilizar a localização do dispositivo;
* Visualizar entregas em mapas;
* Organizar e acompanhar rotas;
* Consultar informações das entregas de forma rápida pelo celular.

O projeto também tem como objetivo explorar uma nova stack de desenvolvimento, utilizando **Vue.js e TypeScript**, além de trabalhar com recursos do navegador e armazenamento local.


## 🔨 Desenvolvimento

O desenvolvimento será realizado de forma incremental, começando pela estrutura da aplicação e gerenciamento das entregas e, posteriormente, incorporando recursos como câmera, OCR, GPS, mapas e rotas.
